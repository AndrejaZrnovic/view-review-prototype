# CLAUDE.md

## STRICT GIT RULES — READ FIRST

**NOTHING EVER GETS PUSHED DIRECTLY WITHOUT THE OWNER'S EXPLICIT PERMISSION.**

- NEVER run `git push` (to any branch, including `main`/`master`) unless the owner has explicitly said so in chat for that specific push.
- NEVER force-push, under any circumstances.
- All changes go through **Pull Requests only**: create a feature branch, commit there, and open a PR for the owner to review. Never commit or merge directly to `main`/`master`.
- NEVER merge a PR. The owner merges.
- Permission is per-action: approval for one push or PR does not carry over to later ones.
- If unsure whether something is allowed, ask first.
