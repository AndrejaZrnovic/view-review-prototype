# Blue sneaker stimulus set

The original is [“Tapaha鞋子.jpg” on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Tapaha%E9%9E%8B%E5%AD%90.jpg), shown on its file page as [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). It depicts two blue canvas sneakers. `original.jpg` was downloaded on 2026-11-03. All AI PNGs were created with the built-in image-generation tool, using the original photo or the faithful `ai-control-front.png` as an edit target. Prompts required the same shoe pair, position, colors, eyelets, tag, seams, and soles except for the named edit.

| File | Answer key | Intended change from original |
| --- | --- | --- |
| `ai-control-front.png` | No discrepancy | Slightly different camera angle |
| `ai-control-soft-light.png` | No discrepancy | Slightly different soft light |
| `ai-control-cool-light.png` | No discrepancy | Slightly cooler light |
| `ai-error-no-tag.png` | Discrepancy | Small white heel tag removed |
| `ai-error-black-eyelet.png` | Discrepancy | Top visible silver eyelet made black |
| `ai-error-no-side-seam.png` | Discrepancy | Curved stitched side seam removed from upper shoe |
| `ai-error-smooth-sole.png` | Discrepancy | Fine ribbing removed from upper shoe's sole edge |

`index.html` offers this as an alternate built-in set. The DSLR set is the default, and the bottle set remains selectable for practice. The answer key is in the `SHOES.views` data and is revealed only at debrief; participant exports include each image's key and participant flag/note.

Before recruitment, run a blinded pilot with several people who did not make the images. Confirm each intended change is visible at the available zoom level and ask reviewers to identify any unplanned changes in controls or error images. AI rendering can alter tiny details unintentionally; do not treat this key as validated ground truth until that image audit is complete. No participant responses are included here.
